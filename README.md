# php-test-task

Simple PHP user authentication system including:  
- Registration  
- Login with CAPTCHA  
- Profile page  
- Logout  

## Files

- `register_3[1].php` – форма и логика регистрации пользователя  
- `login_3[2].php` – форма и логика входа с проверкой CAPTCHA  
- `logout_3[1].php` – выход пользователя из системы  
- `profile_3[1].php` – страница профиля пользователя  
- `users[1].json` – тестовые данные пользователей
